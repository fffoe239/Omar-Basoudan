# لعبة الجري والقفز

لعبة ويب بسيطة عربية ومليئة بالمرحلة: 100 مرحلة، كل مرحلة أصعب من السابقة، مع حواجز لا بد من القفز فوقها. إذا اصطدمت بالحاجز، تموت وتعود إلى المرحلة نفسها.

## التشغيل
- افتح ملف `index.html` مباشرة في المتصفح.
- أو خدم المشروع عبر أي خادم محلي مثل:
  - `python -m http.server 8000`
  - ثم افتح `http://localhost:8000`

## المراحل
- المرحلة 1 إلى 10: شارع عربي
- المرحلة 11 إلى 20: حي عربي
- المرحلة 21 إلى 30: سوق
- المرحلة 31 إلى 40: صحراء
- المرحلة 41 إلى 50: جبل
- المرحلة 51 إلى 60: مدينة
- المرحلة 61 إلى 80: طريق سريع
- المرحلة 81 إلى 100: منطقة متقدمة

## التحكم
- للأعلى أو المسافة: قفز
- اليمين/يسار أو A/D: حركة
